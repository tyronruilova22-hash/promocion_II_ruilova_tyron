Programación II

Bienvenido al repositorio de la asignatura Programación II. Este espacio está destinado a almacenar el material, prácticas, proyectos y código desarrollados a lo largo del curso.

🚀 Tecnologías y Herramientas del Curso

En esta materia profundizaremos en el desarrollo de software utilizando las siguientes tecnologías:

🐍 Python

Python es un lenguaje de programación de alto nivel, interpretado y de propósito general. Es reconocido por su sintaxis clara y legible, lo que facilita el desarrollo rápido de aplicaciones. En este curso servirá como la base fundamental para el diseño de lógica, programación orientada a objetos y estructuras de datos.

🌐 Django

Django es un marco de trabajo (framework) de desarrollo web de código abierto escrito en Python. Sigue el patrón de arquitectura MVT (Modelo-Vista-Template) y está diseñado para ayudar a los desarrolladores a llevar sus aplicaciones desde el concepto hasta la realización lo más rápido posible, priorizando la seguridad, escalabilidad y mantenibilidad.

💼 Odoo

Odoo es un sistema ERP (Enterprise Resource Planning) y CRM de código abierto, extensible y modular, construido sobre Python y PostgreSQL. En la asignatura exploraremos el desarrollo de módulos personalizados en Odoo para automatizar y gestionar procesos de negocio de manera eficiente.

📚 Contenido del Repositorio

El repositorio se encuentra organizado de la siguiente manera:

/unidad-1-python: Ejercicios y proyectos de consolidación en Python avanzado y POO.

/unidad-2-django: Proyectos y desarrollo de aplicaciones web con Django.

/unidad-3-odoo: Módulos, configuraciones y personalizaciones para Odoo.

/recursos: Guías, lecturas complementarias y enlaces de interés.

🛠️ Requisitos Previos

Para ejecutar los proyectos de este repositorio, necesitarás contar con:

Python 3.10+

Git

PostgreSQL (para el desarrollo con Django y Odoo)

Un entorno de desarrollo como VS Code o PyCharm

💻 Instrucciones de Uso

Clonar el repositorio:

git clone https://github.com/tu-usuario/programacion-ii.git
cd programacion-ii


Crear y activar un entorno virtual:

python -m venv venv
# En Linux/macOS:
source venv/bin/activate
# En Windows:
venv\Scripts\activate


Instalar dependencias:

pip install -r requirements.txt
